# Amazon Sales Performance Dashboard

## Project Overview
An interactive and dynamic Power BI Dashboard designed to analyze Amazon sales performance, track core revenue metrics, and optimize logistics. This dashboard provides granular insights into revenue distribution, order fulfillment channels, product performance, and courier status to support data-driven decision-making.

---

## Key Metrics & Insights
* **Total Revenue:** Evaluated and structured a sales dataset representing **₹11.58M** in total amount.
* **Top Sales Categories:** Identified high-performing product segments including T-shirts, Trousers, and Wallets.
* **Logistics & Delivery:** Monitored courier delivery performance across statuses, highlighting that **85.6%** of orders were successfully **Shipped**.
* **Fulfillment Analysis:** Compared operational distribution channels between **Amazon (FBA)** and **Merchant (FBM)** setups to assess shipping efficiency.

---

## Tech Stack & Tools
* **Data Visualization:** Power BI Desktop
* **Design & Layout:** Custom 4:3 Aspect Ratio canvas configuration with embedded dashboard alignment.
* **Data Sources:** Amazon sales transactional datasets.
